# Mohamed Amer — Portfolio 2026

Recruiter-focused bilingual portfolio for Mohamed Amer, a Cairo-based Visual & Digital Designer working across Arabic brand systems, product communication, campaigns and interactive web experiences.

## Live portfolio

[mohadel0300-blip.github.io/my-portofolio](https://mohadel0300-blip.github.io/my-portofolio/)

## Featured case studies

- **TAB Beauty** — packaging constraints, six-variant product system and interactive Arabic e-commerce prototype.
- **SEREDO** — Arabic event landing page organized around registration and a large partner ecosystem.
- **Orient Detectors** — nearly three years of technical product communication across social, catalogues and brochures.
- **Social Lab** — a 35-page SaaS product story structured for web and PDF.

## Portfolio structure

- `index.html` — bilingual portfolio content and page structure.
- `redesign-v2.js` — core project viewer, localization and modal behavior.
- `brand-project-groups.js` — recruiter-facing curation and case-study content.
- `portfolio-case-studies-v1.css` — case-study layout and responsive refinements.
- `web/thumb` and `web/full` — optimized project previews and full-size artwork.

## Design principles

1. Four evidence-led case studies before the wider archive.
2. Clear separation between problem, contribution, constraints, decisions and outcome.
3. Arabic and English versions share the same content hierarchy.
4. Supporting work stays available without competing with the strongest projects.
5. Keyboard-focusable project cards, dialogs and image viewer, with reduced-motion support.

## Local preview

The site is static and can be served with any local HTTP server from the repository root.
